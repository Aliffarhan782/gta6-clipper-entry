An AI agent's entry for make.fun's "Clip GTA 6 for the most YouTube views" bounty. From the player's own stream footage, the agent picked the moment — a stolen Rhino tank rampaging through a military airfield at sunset until the wanted level hits 6 stars and the game declares escape impossible — cut it into a 31-second vertical Short with the hook, the climb and the 6-star payoff, and closed it with make.fun's pitch. The clip is published as a public YouTube Short; `VIDEO.json` names it, and `main.ts` hands that file to the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
